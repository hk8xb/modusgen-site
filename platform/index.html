The software around your models.

One model API for your own and frontier models, managed coding agents and an SEI dashboard, all running inside your network.

Model API

One API for every model your teams use: your own open-weight models and frontier ones, with a key, a limit and a usage record for every call.

  • OpenAI- and Anthropic-compatible endpoints
  • Each model served from your machines or a frontier provider
  • Keys and rate limits per person, team and app
  • Tokens, cache hits and latency recorded for every call

Coding agents

OpenCode on every developer machine, pointed at your model API through its own managed settings. A doctor checks each machine end to end.

  • Rolled out through your device management
  • No direct route to outside model providers
  • Upstream OpenCode, unmodified

SEI dashboard

Software engineering intelligence for the move: adoption, delivery and model cost by team, so you can see what the agents change.

  • Adoption and cost from the gateway's own records
  • Delivery figures from read-only Git aggregates
  • Team level only, never individual rankings
