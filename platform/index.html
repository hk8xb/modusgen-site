The software around your models.

A model gateway, coding agents and a company portal, plus the evaluations and serving stack behind them, all running inside your network. A company agent for every employee is in development.

Book a call See the economics

Model gateway

One API for every model your teams and apps use, open-weight and frontier alike, with a key, a limit and a usage record for every call.

  • OpenAI- and Anthropic-compatible endpoints
  • Each model served from your machines or a frontier provider
  • Keys and rate limits per person, team and app
  • Tokens, cache hits and latency recorded for every call

Company agent In development

An assistant for every employee, running on your own models through the gateway and signed in with your company identity.

  • Built on the same gateway, keys and limits
  • Your data rules decide which models it may call
  • Usage and cost by team, in the portal

Coding agents

OpenCode on every developer machine, pointed at your gateway through its own managed settings. A doctor checks each machine end to end.

  • Rolled out through your device management
  • No direct route to outside model providers
  • Upstream OpenCode, unmodified

Company portal Preview

The portal your admins run and your leaders read: an SEI dashboard of adoption, delivery and cost by team, with keys and members alongside it.

  • Adoption and cost from the gateway's own records
  • Delivery figures from read-only Git aggregates
  • Team level only, never individual rankings

Evaluations

The same tasks from your own repositories, run on each candidate model through the gateway, with every finished task priced. The evidence behind every model change.

  • Paired runs against the model you use today
  • Cost per accepted task, with every attempt counted
  • Run again whenever a model or engine changes

Serving and monitoring

Unmodified open-source serving and monitoring, set up and kept current in your cloud account or on machines you own.

  • vLLM to serve your open-weight models
  • Prometheus and Grafana for health, capacity and GPUs
  • Terraform and install scripts for AWS, Azure or your own racks
  • New open-weight releases tested, then rolled out

One call, end to end.

A developer's coding agent asks for a change. This is that one call, through the gateway to your GPUs and back, drawn from the record the gateway writes for every call.

The record the gateway writes

{
  "time": "2026-11-11T14:02:09Z",
  "team": "payments",
  "user": "dev-0412",
  "model": "open-coder",
  "dialect": "chat",
  "status": 200,
  "input_tokens": 61240,
  "cached_input_tokens": 55116,
  "output_tokens": 412,
  "queue_ms": 0,
  "first_token_ms": 380,
  "duration_ms": 6120,
  "truncated": false,
  "error_class": "none"
}

Real field names, sample values. Prompts and answers are never recorded.

The totals the SEI dashboard will read
