Which route fits.

A hosted endpoint
The cheapest start for almost all work, and the right place for any tier whose bill is below one server's monthly cost.

For coding agents at team scale, or any tier once its Claude bill passes one server's monthly cost: about $17,900 for frontier, $11,100 for workhorse and $7,000 for high-volume. Every request stays inside.
